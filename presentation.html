General Context

Visual servoing enables robot control using visual feedback from cameras mounted on the manipulator.

Introduction to Visual Servoing

  • Visual servoing uses image data to control robot motion in closed-loop
  • Camera provides real-time feedback for precise positioning tasks
  • Two main approaches: Image-Based (IBVS) and Position-Based (PBVS)
  • Applications: manufacturing, surgery, autonomous navigation, inspection
  • Key challenge: achieving robust convergence with large displacements

Problem Statement

Limitations of Classical Approaches

  • IBVS suffers from local minima and camera retreat issues
  • PBVS requires accurate 3D model and is sensitive to calibration errors
  • Large displacement scenarios cause feature tracking failures
  • High-frequency image components introduce noise sensitivity

Research Objective

Develop a direct visual servoing method that leverages multiscale image decomposition for robust convergence across large displacements while maintaining precision.

Methodology Overview

  • Direct approach: use pixel intensities as visual features (no feature extraction)
  • Multiscale decomposition: process image at multiple resolution levels
  • Coarse-to-fine strategy: converge at low resolution first, refine at higher scales
  • Interaction matrix formulation adapted for multiscale luminance features
  • Exponential convergence guaranteed via Lyapunov stability analysis

Multiscale Decomposition Approach

Gaussian Pyramid Construction

  • Image decomposed into L levels using Gaussian smoothing and subsampling
  • Each level captures features at different spatial frequencies
  • Low-resolution levels provide wide convergence basin
  • High-resolution levels ensure sub-pixel positioning accuracy

Scale Selection Strategy

Automatic scale switching based on error norm thresholds ensures optimal convergence speed at each phase of the servoing task.

Visual Features

Photometric Visual Servoing Features

  • Feature vector: s = I (entire image luminance vector)
  • Desired feature: s* = I* (desired image captured at goal pose)
  • Error: e = I - I* computed directly on pixel intensities
  • No geometric feature extraction or matching required

Interaction Matrix

The interaction matrix L_I relates image intensity variations to camera velocity, computed analytically using image gradients and depth information.

Control Law

Velocity Command Computation

The camera velocity is computed as:

v = -λ L_I+ (I - I*)

  • λ : adaptive gain for convergence speed control
  • L_I+ : pseudo-inverse of the interaction matrix
  • Multiscale extension: apply at current pyramid level
  • Smooth transitions between scales prevent discontinuities

Experimental Results

Validation on 6-DOF Robotic Platform

  • Tested on Gantry robot with eye-in-hand camera configuration
  • Large initial displacements: up to 30cm translation, 25deg rotation
  • Convergence achieved in all tested configurations with multiscale
  • Sub-millimeter final positioning accuracy (< 0.5mm, < 0.1deg)
  • 50%% faster convergence compared to single-scale approach

Comparison with Existing Methods

Performance Benchmarks

  • vs. Classical IBVS: larger convergence domain, no local minima observed
  • vs. Single-scale direct VS: 2x wider convergence basin, faster convergence
  • vs. PBVS: no 3D model required, robust to calibration errors
  • vs. Hybrid approaches: simpler implementation, comparable accuracy

Key Advantage

The multiscale framework combines the wide convergence of coarse features with the precision of fine-scale information, bridging the gap between IBVS and PBVS.

Conclusion & Perspectives

Key Contributions

  • Automatic scale selection strategy for optimal performance
  • Experimental validation demonstrating superior robustness
  • Applicable to various robotic platforms and camera configurations

Future Work

Extension to dynamic scenes, integration with deep learning features, and real-time GPU implementation for high-resolution servoing.
