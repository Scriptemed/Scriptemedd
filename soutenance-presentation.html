Direct Photometric Visual Servoing (PVS)

Uses the entire image as a feature vector. The error signal is computed directly from pixel intensity differences between the current and desired images. Elegant but fragile under non-ideal conditions.

e(t) = I(t) - I*   |   v = -λ LI+ (I - I*)

Fourier Transform: Continuous & Discrete

The mathematical foundation for analyzing signals in the frequency domain.

Continuous Fourier Transform (CFT)

F(ω) = ∫−∞+∞ f(t) · e−jωt dt
f(t) = (1 / 2π) · ∫−∞+∞ F(ω) · ejωt dω

Decomposes a continuous signal f(t) into an infinite spectrum of complex sinusoids.

Discrete Fourier Transform (DFT)

X[k] = Σn=0N−1 x[n] · e−j2πkn/N,  k = 0, 1, …, N−1
x[n] = (1 / N) · Σk=0N−1 X[k] · ej2πkn/N

Sampled version for discrete signals — used directly on digital images and computed efficiently via the FFT (O(N log N)).

CFT

Continuous t and ω, theoretical framework

DFT

Finite samples, practical for digital signal & image processing

Frequency Analysis & Its Limits

The Fourier Transform provides global frequency content but loses all spatial localization — critical for non-stationary signals like images.

Fourier Limitation

Cannot localize where a frequency component exists in space

Need for Wavelets

Multi-resolution analysis provides both spatial and frequency information simultaneously

Wavelet Transforms: DWT & CWT

Wavelet transforms provide multi-resolution analysis with both spatial and frequency localization.

DWT (Discrete Wavelet Transform)

Separates global trends (illumination) from structural details (edges, textures). Produces 4 sub-bands: LL, LH, HL, HH

CWT (Continuous Wavelet Transform)

Continuous version with redundant representation — high computational cost, not suitable for real-time

2D DWT decomposition: one approximation (LL) + three detail sub-bands (LH, HL, HH).

Lifting Wavelet Transform (LWT)

An optimized variant of the DWT designed for real-time computation through in-place lifting steps.

LWT (Lifting Wavelet Transform)

Spatial optimization via in-place computation. No complex multiplications required, only additions and shifts. Ideal for embedded real-time systems.

Control Strategies: Switching & Smart Switch

Two complementary control laws drive the system: a switching mechanism for DWT-PVS and an optimal coarse-to-fine strategy for LWT-PVS.

DWT-PVS Switching Control Law

{
vc = −λ · L̂w,coarse+ · ew,coarse   if ||e|| > ε  (Large displacement)
vc = −λ · L̂w,fine+ · ew,fine   if ||e|| ≤ ε  (Near convergence)
Switches dynamically based on the error threshold ε.

LWT-PVS Optimal Control Law

{
vc = −λ · L̂LWT,coarse+ · eLWT,coarse   if ||e|| > ε  (Avoids local minima)
vc = −λ · L̂LWT,fine+ · eLWT,fine   if ||e|| ≤ ε  (High precision)
✓ Only ONE velocity is computed and sent to the robot at any time t.
